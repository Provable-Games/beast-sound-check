# Beast Sound Check

A phone-first listening test for the onchain MIDI player ([onchain-midi-player](https://github.com/Provable-Games/onchain-midi-player)): Casey Wescott's Beast compositions, every TinyChip preset and drum, and edge cases. Each track is the exact page a Beast's `token_uri` carries. Tracking issue: [onchain-midi-player#52](https://github.com/Provable-Games/onchain-midi-player/issues/52).

Open https://provable-games.github.io/beast-sound-check/ on your phone.
