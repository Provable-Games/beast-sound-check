k-rate detune ear test

pocket-synth connects the vibrato oscillator (CC1) to every note's detune. Chrome normally recomputes the pitch for each audio sample (a-rate). With a k-rate detune it recomputes it once per 128 frames, which is cheaper, but the pitch then moves in steps 2.7 ms long (48 kHz). Each pair below is the same score through the real engine; one file is a-rate and one k-rate. Which is which is hidden until you open the answer.

How to listen. Use headphones first, then the phone speaker. Play 1, then 2, then 1 again, a few times, and say whether you hear any difference and in which. Keep the volume the same for both. Note the pair, which one you picked, how sure you are, and your phone and Chrome version. If you cannot tell them apart, that is the result.

Rendered offline with the Node package node-web-audio-api, not Chrome, dry (no reverb), 48 kHz mono 16-bit, both files of a pair at the same gain. There a connected k-rate detune holds its first input sample for each 128-frame quantum, which is what Chrome's does too, but the oscillator itself is not Chrome's, and a phone's speaker and audio path are not this page's.

Held note, vibrato at moderate depth

A held plain sawtooth (A4) with the engine's 5 Hz vibrato at CC1 = 48, about 38 cents each way. Listen for a buzz, roughness or grainy edge on the vibrato in one of the two, especially in the upper harmonics.

Answer

File 1 is k-rate, file 2 is a-rate.

Held note, vibrato at full depth

The same note at CC1 = 127, 100 cents each way, the deepest the engine goes. The pitch changes fastest at the vibrato's zero crossings, which is where a staircase would show most.

Answer

File 2 is k-rate, file 1 is a-rate.

Slow pitch bend sweep

The same note glides up two semitones, down to two below its start, then back, as 200 pitch bend messages a second over 3 s. Listen for the glide sounding stepped or rough in one of the two.

Answer

File 1 is k-rate, file 2 is a-rate.

FM bell with vibrato

Two struck tubular bells (C5, then G5) with CC1 = 64, about 50 cents each way. The bell's partials are the highest frequencies here, where the same pitch step is the most Hz.
